# NEDAL AI — Starter

واجهة أولية عربية/ألمانية/إنجليزية متجاوبة للموبايل.

## تشغيلها
افتح `index.html` في المتصفح، أو ارفع الملفات إلى مستودع GitHub Pages.

## مهم
هذه واجهة تجريبية وليست متصلة بمحرك ذكاء اصطناعي حقيقي بعد. لإضافة الذكاء الاصطناعي يجب إنشاء خادم وسيط آمن وربط مزود AI من جهة الخادم. لا تضع مفاتيح API في `index.html`.

## النشر
يمكن نشر واجهة الويب عبر GitHub Pages بعد رفع `index.html` إلى مستودع عام وتفعيل Pages من إعدادات المستودع. تحويلها إلى تطبيق Android ونشرها على Google Play مرحلة منفصلة وتتطلب بناء حزمة Android، الاختبار، وسياسات Google Play.
